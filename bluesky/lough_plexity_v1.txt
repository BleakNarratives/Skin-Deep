## Multi-Model LOUGH Coach (Your Rig Eats This)

```python
# lough_ensemble.py — 3 models, 1 truth
import ollama

models = {
    'deepseek': "Rate 0-10. Brutal 8 words.",
    'gemma2': "Surgical correction. 5 words max.", 
    'phi3': "Real-time fix. 3 words."
}

def ensemble_coach(error_px):
    votes = {}
    for model, style in models.items():
        prompt = f"Hand error: {error_px}px. {style}"
        response = ollama.generate(model=model, prompt=prompt)['response']
        votes[model] = response
    
    # Majority vote + best roast
    consensus = max(votes.items(), key=lambda x: "good" in x[1].lower())
    return consensus[1], votes
```
